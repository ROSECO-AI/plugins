# История изменений

## 1.0.0 — 2026-11-26

- Первая публичная версия плагина.
- Добавлен навык развёртывания и сопровождения read-only мониторинга лицензий Vitro-CAD.
- Добавлен Python-шаблон с SQLite, HTML-дашбордом, macOS Keychain и Windows DPAPI.
- Добавлены ссылки на официальную справку Vitro-CAD, правила безопасности и расширенный промпт.
