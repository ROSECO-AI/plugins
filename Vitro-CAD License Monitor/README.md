# Мониторинг лицензий Vitro-CAD

Плагин Codex для развёртывания локального read-only мониторинга занятости пользовательских лицензий WEB и PRO в Vitro-CAD MP.

Агент:

- проверяет окружение и официальную справку Vitro-CAD;
- устанавливает обезличенный Python-сервис в отдельную папку;
- помогает безопасно выполнить вход и обнаружить список пользователей;
- сохраняет в SQLite только агрегаты;
- строит автономный HTML-дашборд за день, неделю и месяц;
- после успешного ручного замера настраивает периодический запуск после подтверждения пользователя.

Пароль и токен не передаются в чат. Токен хранится в macOS Keychain или в защищённом Windows DPAPI-хранилище. В SQLite и HTML не записываются имена, e-mail и другие данные сотрудников.

## Установка

```text
codex plugin marketplace add ROSECO-AI/plugins --ref main
codex plugin add vitro-cad-license-monitor@roseco-ai-plugins
```

Проверьте установку командой `codex plugin list`, начните новый чат и попросите настроить мониторинг. Подробная процедура — в [INSTALL.md](INSTALL.md).

## Границы версии 1.0.0

- поддерживаются macOS и Windows;
- Linux пока не поддерживается из-за отсутствия единого проверенного защищённого хранилища;
- двухфакторный вход не автоматизирован: плагин останавливается и объясняет ограничение;
- мониторинг работает, только когда компьютер включён и может запускать задачу;
- плагин не является официальным продуктом или компонентом ООО «Витро Софт».

Плагин распространяется по лицензии Apache-2.0.
