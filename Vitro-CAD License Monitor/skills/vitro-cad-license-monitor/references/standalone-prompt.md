# Автономный промпт для агента

Этот текст можно передать агенту, если плагин уже установлен, но навык не включился автоматически.

```text
Используй установленный плагин «Мониторинг лицензий Vitro-CAD». Разверни на этом компьютере отдельный локальный read-only мониторинг WEB- и PRO-лицензий Vitro-CAD.

Перед началом прочитай все references навыка и сверь текущую схему входа и REST API с официальными материалами:

- главная справка: https://portal.vitrocad.ru/spaces/MP/pages/38928388/Vitro-CAD%2BMP%2B-%2B%D0%94%D0%BE%D0%BA%D1%83%D0%BC%D0%B5%D0%BD%D1%82%D0%B0%D1%86%D0%B8%D1%8F
- работа с лицензиями: https://portal.vitrocad.ru/pages/viewpage.action?pageId=56855868
- получение токена Login: https://portal.vitrocad.ru/pages/viewpage.action?pageId=105185465
- руководство администратора с разделом REST API: https://vitrocad.ru/images/documents/Vitro-MP-%D0%A0%D1%83%D0%BA%D0%BE%D0%B2%D0%BE%D0%B4%D1%81%D1%82%D0%B2%D0%BE-%D0%B0%D0%B4%D0%BC%D0%B8%D0%BD%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%82%D0%BE%D1%80%D0%B0.pdf

Страницы могут обновляться или требовать входа. Если точная страница недоступна, используй главную справку и поиск по названию метода. Не используй GUID из документации как боевые значения.

Базовые маршруты, которые нужно сверить со справкой для установленной версии: `POST /api/security/Login` для получения токена и `POST /api/item/getRecursive/{listId}` для read-only чтения элементов списка. Токен передавай в `Authorization` точно в формате, который указан в актуальной справке; не добавляй `Bearer` без явного указания.

Пользователь не является программистом. Сам проверь ОС, Python, права на папку и доступный планировщик. Задавай простые вопросы по одному. Спроси только URL портала, логин, лимиты WEB/PRO, часовой пояс и расписание. Не спрашивай GUID и internalName полей.

Пароль и токен нельзя присылать в чат. Пароль вводится только скрыто в терминале и не сохраняется. Токен хранится в macOS Keychain или Windows DPAPI.

Установи встроенный в плагин Python-шаблон в отдельную папку. Выполни configure и login. Проверь список пользователей и поле активной лицензии read-only запросами. Не печатай и не сохраняй сырые записи.

Выполни один живой collect, создай SQLite-историю и HTML-дашборд. Проверь, что на диске остались только агрегаты, а кнопки «День / Неделя / Месяц» работают в статическом HTML.

Только после успешного ручного замера покажи точное расписание и получи подтверждение. Задача по расписанию должна сначала запускать collect и только при успехе обновлять dashboard.

При 401 дай готовую команду login. 403 называй ошибкой прав, а не токена. LicenseViolationException обозначает проблему выдачи лицензии учётной записи, а не доказанное число занятых лицензий. Не пересобирай дашборд из старых данных после неудачного сбора.

В финале сообщи точный путь к проекту и дашборду, результат первого замера, что проверено, как отключить расписание и какие ограничения остались.
```
