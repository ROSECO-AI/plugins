# Безопасность и эксплуатация

## Секреты

- Пароль живёт только в памяти процесса во время `login`.
- На macOS токен хранится как generic password в Keychain.
- На Windows токен шифруется DPAPI в контексте текущего пользователя. Шифртекст сам по себе не должен переноситься между учётными записями.
- В `config.json` можно хранить URL, логин, ID списка, internalName поля, лимиты и дату истечения. Пароль и токен там запрещены.

## Данные

Разрешённая схема SQLite:

- UTC-время замера;
- число WEB;
- число PRO;
- число записей без активной лицензии;
- общее число подсчитанных записей;
- длительность API-запроса.

Сырой API-ответ не записывается. HTML получает только агрегаты.

## Расписание

Безопасная транзакция запуска:

1. `collect`;
2. проверка кода возврата;
3. только при успехе `dashboard`.

Расписание не должно просить пароль. При `401` оно завершается с ошибкой, а агент просит пользователя вручную запустить `login`.

## Восстановление

Храни резервную копию SQLite отдельно от самой папки проекта, если история важна. Перед миграцией проверь:

- что копия открывается SQLite;
- что последний замер совпадает;
- что новая задача расписания использует новый абсолютный путь.
