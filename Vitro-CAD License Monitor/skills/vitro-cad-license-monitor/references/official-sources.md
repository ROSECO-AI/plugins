## Что подтверждено этими источниками

- Файл лицензий содержит количество пользовательских лицензий WEB и PRO.
- Контроль их использования выполняется в списке «Пользователи» по системному атрибуту «Активная лицензия».
- Активная лицензия назначается при авторизации и освобождается при выходе, административном выходе, блокировке, удалении, удалении ключа лицензии или после периода отсутствия API-активности.
- Вход выполняется `POST /api/security/Login`.
- Полученный `token` передаётся как есть в заголовке `Authorization`, без префикса `Bearer`.
- Ответ входа может содержать `expires`, статус сессии и признак необходимости 2FA.

## Границы

Справка регулярно обновляется, а часть страниц может требовать входа. Руководство администратора содержит описания API разных версий. Поэтому перед изменением маршрутов или тела запроса сверь фактическую версию портала и выполни read-only пробу.
