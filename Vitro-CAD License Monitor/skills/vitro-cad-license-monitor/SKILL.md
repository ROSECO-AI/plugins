# Мониторинг лицензий Vitro-CAD

## Результат

Разверни на компьютере пользователя отдельный локальный проект, который:

1. читает системный список «Пользователи» только через REST API;
2. подсчитывает активные WEB и PRO;
3. отбрасывает персональные данные до записи на диск;
4. сохраняет агрегаты в SQLite;
5. строит автономный HTML-дашборд за день, неделю и месяц;
6. может запускаться по согласованному расписанию.

Не считай установку завершённой до реального успешного read-only замера и проверки дашборда.

## Источники и границы

Перед первой установкой или при изменении API-логики прочитай целиком:

- [references/official-sources.md](references/official-sources.md);
- [references/api-discovery.md](references/api-discovery.md);
- [references/security-and-operations.md](references/security-and-operations.md).

Ссылки в справке — это маршрут к источнику, а не гарантия совпадения всех полей в любой инсталляции. Проверяй схему конкретного портала read-only запросами. Не используй GUID из примеров документации как боевые значения.

## Безопасность

- Никогда не проси пароль, токен или cookie в чате.
- Пароль вводится только через `getpass` в локальном терминале.
- Не сохраняй пароль. Токен храни только в macOS Keychain или в Windows DPAPI под текущим пользователем.
- Не выводи сырой ответ входа и сырой список пользователей.
- Не сохраняй имена, e-mail, GUID пользователей и другие поля записей.
- Не используй методы записи, обновления или удаления Vitro-CAD.
- Не открывай дашборд в сеть и не публикуй его во внешней системе без отдельного поручения.

## Порядок работы

### 1. Проверь контур

Определи:

- macOS или Windows;
- Python 3.11 или новее;
- куда можно создать отдельную папку проекта;
- доступен ли локальный терминал со скрытым вводом;
- может ли среда создать локальное расписание.

Если ОС не поддерживается или Python отсутствует, остановись и объясни одно конкретное действие. Не создавай пустой «успешный» проект.

### 2. Собери минимум данных

Задавай простые вопросы по одному. Нужны:

1. HTTPS-адрес Vitro-CAD;
2. логин;
3. купленные лимиты WEB и PRO;
4. часовой пояс, рабочие дни, часы и интервал.

Не спрашивай GUID списка и internalName полей. Это техническая работа агента.

### 3. Установи шаблон

Найди корень плагина по текущему `SKILL.md`. Запусти:

```text
python <plugin-root>/runtime/install.py --target <отдельная-папка-проекта>
```

На Windows при наличии только Python Launcher используй `py -3`. Установщик не перезаписывает непустую папку.

### 4. Настрой и выполни вход

В папке проекта выполни:

```text
python -m vitro_license_monitor.cli configure
python -m vitro_license_monitor.cli login
```

`configure` сохраняет только несекретную конфигурацию. `login` запрашивает пароль скрыто, сохраняет токен в хранилище ОС и записывает только дату его истечения и обнаруженный ID списка.

Если статус входа требует 2FA, первичного пароля или смены пароля, остановись. Не сохраняй промежуточный токен как рабочий.

### 5. Проведи живую проверку

```text
python -m vitro_license_monitor.cli collect
python -m vitro_license_monitor.cli dashboard
python -m unittest discover -s tests -v
```

Сбор считай успешным только при нулевом коде возврата и новой строке в SQLite. Проверь, что таблица `samples` не содержит имён, e-mail и GUID. После этого открой или покажи пользователю `output/license-dashboard.html`.

### 6. Настрой расписание

Только после успешного ручного замера покажи пользователю точное расписание и получи его подтверждение.

Предпочитай штатную запланированную задачу Codex, если она доступна и может работать в нужной локальной папке. Иначе используй:

- macOS: LaunchAgent текущего пользователя;
- Windows: Task Scheduler текущего пользователя без повышенных прав.

Задача должна сначала выполнить `collect` и только при его успехе — `dashboard`. При неудачном сборе не пересобирай дашборд из старых данных.

## Диагностика

- `401`: токен отсутствует или истёк. Дай готовую команду `login` для текущего проекта.
- `403`: недостаточно прав чтения. Не называй это истечением токена.
- `LicenseViolationException`: учётная запись не получила нужную лицензию. Это не доказывает точную занятость лимита.
- Сетевую, локальную или серверную ошибку не называй ошибкой токена без кода или ответа, который это подтверждает.
- Если схема отличается, сообщи названия кандидатов-полей без значений записей и запроси решение. Не угадывай.
