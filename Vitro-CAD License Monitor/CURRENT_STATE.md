# Текущее состояние

Дата: 2026-11-26

- Подготовлен skills-only плагин `vitro-cad-license-monitor` версии 1.0.0.
- В плагин входит обезличенный Python-шаблон локального read-only мониторинга, тесты и установщик.
- Справочные материалы опираются на официальный портал Vitro-CAD и руководство администратора.
- Защищённое хранение токена реализовано для macOS Keychain и Windows DPAPI.
- Linux и автоматизация 2FA не входят в версию 1.0.0.
- Реальный вход и замер на сторонней инсталляции Vitro-CAD должны выполняться устанавливающим пользователем; публичный пакет не содержит учётных данных или клиентских GUID.
