# Установка и первый запуск

## 1. Установите плагин

```text
codex plugin marketplace add ROSECO-AI/plugins --ref main
codex plugin add vitro-cad-license-monitor@roseco-ai-plugins
```

Затем выполните `codex plugin list` и начните новый чат.

## 2. Дайте агенту задачу

```text
Настрой на этом компьютере read-only мониторинг занятости лицензий WEB и PRO в Vitro-CAD. Проведи безопасный тестовый сбор, создай дашборд и после этого предложи расписание.
```

Агент сам проверит Python, операционную систему, доступ к файлам и официальную справку. Он не должен спрашивать GUID списка или имена API-полей.

## 3. Что нужно сообщить

Понадобятся:

- HTTPS-адрес вашего Vitro-CAD;
- логин учётной записи с правом чтения списка «Пользователи»;
- количество купленных WEB- и PRO-лицензий;
- часовой пояс, рабочие дни и часы.

Пароль нельзя присылать агенту. Вводите его только после скрытого запроса в терминале. При таком вводе не отображаются ни символы, ни точки.

## 4. Проверьте результат

Установка считается завершённой, если:

- вход выполнен без публикации токена;
- выполнен один реальный read-only замер;
- в SQLite есть только агрегаты;
- HTML-дашборд открывается и показывает замер;
- агент сообщил путь к дашборду и способ остановки расписания.

Неудачный запрос API или созданный пустой дашборд не являются подтверждением успеха.
