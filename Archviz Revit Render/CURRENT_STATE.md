- Публичный источник для установки: `https://github.com/ROSECO-AI/plugins`; маркетплейс Codex описан в корневом `.agents/plugins/marketplace.json`.

- Для стабильности старого QR-кода существует также отдельный публичный репозиторий `ROSECO-AI/archviz-revit-render`; этот репозиторий `ROSECO-AI/plugins` является основным источником дальнейших изменений.

## Принятые решения

- Основные виды Revit/BIM задают камеру и геометрию. Вспомогательные материалы уточняют сцену и не становятся дополнительными обязательными ракурсами.
- Для экстерьера генплан/СПОЗУ задаёт расположение объектов, покрытия, озеленение и назначение сооружений по читаемой легенде и экспликации. При отсутствии этих сведений работа продолжается по достоверным данным.
- Для экстерьера необходимо определить адрес или координаты по материалам либо запросить их у пользователя. Существующее окружение за пределами участка проверяется по доступным картам и фотографиям.
- При реконструкции фотографии существующего объекта уточняют цвет и фактуру сохраняемых элементов; новые и заменяемые элементы визуализируются по проекту.
- Серия ракурсов одного проекта опирается на одну мастер-сцену. Генеративная графика не гарантирует инженерную точность BIM-модели.

## Проверки, которые ещё нужны

1. Проверить чтение легенды покрытий и экспликации на разрешённом генплане, а также работу с неполным генпланом.
2. Проверить передачу сохраняемых материалов на рендере реконструкции по разрешённым фотографиям.
3. Проверить поведение версии `2.1.1` в новом чате на разрешённых проектных материалах.
