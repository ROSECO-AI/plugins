# Archviz Revit Render — правила проекта

- Этот каталог — исходник плагина. Установленный кэш в `.codex/plugins/cache` служит только для чтения и сравнения.
- Сохраняйте имя плагина `archviz-revit-render`, структуру `skills/archviz-revit-render/SKILL.md` и идентичность существующего плагина при обновлениях.
- Изменения поведения фиксируйте в `CHANGELOG.md` и `CURRENT_STATE.md`; синхронизируйте версии в `plugin.json` и `.codex-plugin/plugin.json`.
- Не включайте в пакет исходные чертежи, фотографии, рендеры заказчиков, адреса объектов, персональные данные и секреты. Для проверок используйте разрешённые материалы или синтетические примеры.
- Перед публикацией сравнивайте изменённый пакет с текущим релизом и отдельно проверяйте результат обновления в целевом приложении. Не считайте локальную редакцию автоматически установленной.
- Существенный контекст разработки храните в этом репозитории. При появлении GitHub-репозитория добавьте его как удалённый источник без переноса конфиденциальных материалов.
