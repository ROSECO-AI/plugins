# Archviz Revit Render

Исходный проект плагина для подготовки фотореалистичных визуализаций по видам Revit/BIM. Плагин содержит переносимый навык `archviz-revit-render`: он последовательно принимает основные виды и вспомогательные материалы, анализирует генплан и создаёт отдельные изображения для целевых ракурсов.

## Состав

- `plugin.json` — основной манифест плагина.
- `.codex-plugin/plugin.json` — совместимый манифест для клиентов, использующих старую структуру.
- `skills/archviz-revit-render/SKILL.md` — правила работы навыка.
- `CURRENT_STATE.md` — текущая версия, происхождение исходников и открытые вопросы.
- `CHANGELOG.md` — история локальных редакций.

## Основной сценарий

1. Пользователь передаёт основные виды BIM-модели, по одному итоговому рендеру на вид.
2. Навык отдельно запрашивает имеющиеся вспомогательные материалы, включая генплан/СПОЗУ, фотографии и дополнительные BIM-ракурсы.
3. При реконструкции фотографии существующего объекта уточняют цвет и фактуру сохраняемых элементов; новые и заменяемые элементы визуализируются по проекту.
4. Для экстерьера навык определяет местоположение по материалам. Если это невозможно, запрашивает адрес или координаты. Генплан служит источником размещения объектов, экспликации, покрытий, озеленения и других читаемых проектных сведений. Недостающие сведения о покрытиях и назначении не задерживают генерацию.
5. Для серии видов навык ведёт одну мастер-сцену и проверяет согласованность геометрии, элементов площадки и окружения.

Генеративное изображение не подтверждает инженерную точность модели. При необходимости геометрию сверяют в Revit или специализированной среде визуализации.

## Разработка и проверка

Меняйте исходники здесь, а не в установленном кэше Codex. При изменении поведения повышайте версию в обоих манифестах и записывайте изменение в `CHANGELOG.md`. Проверяйте синтаксис JSON, структуру навыка и сценарии на материалах, на использование которых есть разрешение. Публикация новой версии в учётной записи и установка на других устройствах — отдельные операции; состояние фиксируется в `CURRENT_STATE.md`.

Исходники опубликованы в приватном репозитории `ROSECO-AI/plugins` в каталоге `Archviz Revit Render/`. Репозиторий содержит каталог `.agents/plugins/marketplace.json` для установки через локальный маркетплейс Codex. Установка на одном компьютере не обновляет удалённый плагин в учётной записи.

Тестовые рендеры котельной от 13.10.2026 остаются в прежней рабочей папке и не входят в исходный пакет плагина. Путь и краткие выводы указаны в `CURRENT_STATE.md`.
