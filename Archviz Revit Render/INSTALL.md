# Установка Archviz Revit Render

Эта инструкция предназначена для тех, кто впервые устанавливает плагин Codex. Archviz Revit Render версии **2.1.1** помогает создавать архитектурные рендеры по видам Revit/BIM и вспомогательным материалам.

[QR-код для презентации (PNG, 1368 × 1368)](assets/archviz-revit-render-plugins-qr.png) ведёт на [страницу плагина](https://github.com/ROSECO-AI/plugins/tree/main/Archviz%20Revit%20Render) с этой инструкцией.

## Где работает плагин

Ниже описана установка в **Codex Desktop или Codex CLI** на macOS и Windows. Установка из GitHub-маркетплейса не добавляет плагин автоматически в браузерный ChatGPT. Для создания изображений в вашем AI-приложении должен быть доступен инструмент генерации изображений.

## Установка в четыре шага

1. Установите [Codex CLI по официальной инструкции OpenAI](https://learn.chatgpt.com/docs/codex/cli#getting-started) и войдите в свою учётную запись. Если команда `codex` уже запускается в Terminal или PowerShell, переходите к следующему шагу.
2. Скопируйте и выполните две команды в Terminal (macOS) или PowerShell (Windows):

   ```text
   codex plugin marketplace add ROSECO-AI/plugins --ref main
   codex plugin add archviz-revit-render@roseco-ai-plugins
   ```

3. Выполните `codex plugin list`. Убедитесь, что `archviz-revit-render@roseco-ai-plugins` имеет статус **installed, enabled**.
4. Перезапустите Codex Desktop или начните новую сессию Codex CLI, затем откройте новый чат.

## Первый рендер

Напишите в новом чате:

> Используй Archviz Revit Render. Подготовь рендер по моим видам Revit и следуй сценарию плагина.

Сначала загрузите скриншоты видов, которые нужно превратить в рендеры. Затем, когда навык отдельно попросит вспомогательные материалы, добавьте имеющиеся генплан/СПОЗУ, дополнительные виды, чертежи и фотографии. Для экстерьера нужен адрес или координаты объекта, если местоположение нельзя определить по чертежам. Для интерьера адрес обычно не требуется.

Фотографии существующего здания при реконструкции помогают передать цвет и фактуру сохраняемых поверхностей. Новые и заменяемые элементы визуализируются по проекту. Генеративные изображения требуют проверки геометрии и не заменяют инженерный рендер из BIM-модели.

## Если установка не сработала

- Проверьте, что команды выполняются в Terminal или PowerShell, а `codex --version` и `git --version` работают.
- Если источник не находится, проверьте доступ к GitHub и повторите команду `codex plugin marketplace add`.
- Если плагин установлен, но не появился в текущем чате, начните новый чат или перезапустите Codex Desktop.

Формат маркетплейса и команды установки описаны в [официальной документации OpenAI](https://developers.openai.com/plugins/build/plugins#add-a-marketplace-from-the-cli).
