# Саммари совещаний

Плагин Codex для подготовки русскоязычных саммари по одной или нескольким стенограммам.

Навык выделяет краткий итог, принятые решения, подтверждённые результаты, поручения, ответственных, сроки, зависимости, риски и открытые вопросы. Он различает факты, предложения и гипотезы, не придумывает отсутствующие данные и исключает секреты из результата.

## Установка

```text
codex plugin marketplace add ROSECO-AI/plugins --ref main
codex plugin add meeting-summary-ru@roseco-ai-plugins
```

Проверьте установку командой `codex plugin list`, затем начните новый чат. Навык может включаться автоматически для задач по подготовке саммари или вызываться явно как `$meeting-summary-ru`.

Подробная процедура приведена в [INSTALL.md](INSTALL.md). [QR-код](assets/meeting-summary-ru-plugins-qr.png) ведёт на эту страницу.

## Состав

- `plugin.json` — переносимый манифест Agent Plugins 1.0.
- `.codex-plugin/plugin.json` — совместимый манифест для локальной установки Codex.
- `skills/meeting-summary-ru/SKILL.md` — правила анализа стенограмм и подготовки саммари.
- `skills/meeting-summary-ru/agents/openai.yaml` — представление навыка в интерфейсе Codex.
