# Установка плагина

## 1. Добавьте маркетплейс ROSECO AI

```text
codex plugin marketplace add ROSECO-AI/plugins --ref main
```

Если маркетплейс уже добавлен, повторять команду не нужно.

## 2. Установите плагин

```text
codex plugin add meeting-summary-ru@roseco-ai-plugins
```

## 3. Проверьте установку

```text
codex plugin list
```

В списке должен появиться `meeting-summary-ru`. После установки начните новый чат, чтобы Codex загрузил навык.

## 4. Используйте навык

Передайте стенограмму и попросите подготовить саммари. Для явного вызова используйте `$meeting-summary-ru`.

Публикация саммари во внешних системах выполняется только по прямому поручению пользователя.
