# BIM Viewer и Autodesk Revit

Сверено 05.11.2026 по доступным материалам официального портала и [примечанию релиза 2026.1.4.4](https://portal.vitrocad.ru/pages/viewpage.action?pageId=94471077). Совместимость команд зависит от установленной версии Vitro-CAD и плагина Revit.

## BIM Viewer

Справка описывает работу с 3D-моделями в браузере, включая форматы IFC, RVT, NWD. Типовые сценарии:

- просмотр модели;
- создание графических и текстовых замечаний на элементах модели;
- регистрация замечаний в Реестре замечаний;
- навигация по замечаниям;
- отображение/скрытие замечаний и подписей;
- панель замечаний с поиском, фильтрацией и переходом к элементу модели.

Для запросов по BIM Viewer уточняй:

- формат модели;
- как модель попадает в Vitro-CAD;
- связана ли модель с карточкой проекта/папкой СХД;
- нужно ли сохранять версии сводной модели;
- требуется ли связка замечаний с процессами исправления.

## Типовые сценарии Revit

### Экспорт

Используй для передачи модели/данных из Revit в Vitro-CAD. Уточни:

- куда в СХД попадает результат;
- какие атрибуты документа/модели заполняются;
- создается новый файл или версия;
- нужен ли IFC/RVT/NWD;
- есть ли требования к именованию.

### Публикация

Используй, когда результат должен стать доступен участникам проекта в Vitro-CAD. Уточни:

- статус документа после публикации;
- права на папку;
- версионность;
- процесс согласования/проверки;
- уведомления или задачи.

### Внешние ссылки

Используй для добавления или обновления связей в Revit. Уточни:

- где хранятся связанные файлы;
- обновляются ли ссылки из Vitro-CAD;
- что делать при переименовании/версии файла;
- нужны ли права на связанные документы.

### Редактирование и сохранение

Используй для сценария "открыть файл, изменить, сохранить обратно". Уточни:

- используется ли клиентская часть Vitro-CAD;
- блокируется ли файл на время редактирования;
- создается ли новая версия;
- как фиксируется автор и дата изменения;
- какой статус документа после сохранения.

## Рекомендации для ответов

- Не смешивай пользовательскую операцию Revit и серверную конфигурацию Vitro-CAD.
- Для внедрения давай цепочку: папка СХД -> тип элемента документа/модели -> атрибуты -> права -> версия -> процесс -> Revit-команда.
- Для ошибок сначала уточняй версию Revit, версию плагина, версию Vitro-CAD, URL площадки, тип операции и текст ошибки.
