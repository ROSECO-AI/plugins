# Карта справки Vitro-CAD MP

Сверено 05.11.2026 по доступному [оглавлению официального портала](https://portal.vitrocad.ru/) и профильным страницам. Часть разделов Confluence требует входа; карта не заменяет проверку конкретной страницы и версии корпоративного портала.

## Верхний уровень

Публичная справка Confluence содержит разделы:

- Аннотация.
- Система документооборота Vitro-CAD версии MP.
- Руководство пользователя: быстрый старт, веб-интерфейс, клиентская часть, приложение "Выпуски".
- Руководство администратора: запуск без настройки, установка компонентов, лицензии, объекты хранения данных, пользователи и доступ, действия с файлами, процессы, REST API, таблицы БД, backup, прочие настройки, отчеты, вычисления, автоматизация, валидаторы, общая конфигурация, ошибки, ИБ, методические материалы, банк решений, диагностика, утилиты.
- История изменений: релизы 2024.1, 2025.1, 2026.0.
- Техническая поддержка Вендора.
- Решения партнеров и утилиты.
- Плагин Vitro-CAD для Autodesk Revit: предварительные настройки, интерфейс, экспорт, публикация, внешние ссылки, редактирование и сохранение.

## Как выбирать раздел

- "Как пользователю загрузить/найти/согласовать документ?" -> пользовательское руководство, веб-интерфейс, клиентская часть, приложение "Выпуски".
- "Как спроектировать структуру проекта?" -> объекты хранения данных, списки, типы элементов, атрибуты, виды, права, процессы.
- "Как настроить маршруты, замечания, роли, исполнителей?" -> процессы, пользователи и доступ, ролевое назначение прав, автоматизация.
- "Как посчитать номер/статус/срок?" -> вычисления, функции и операторы формул, счетчики, валидаторы.
- "Как подключить внешний сервис?" -> REST API, CLI, создание действия с вызовом REST-сервиса, обработчики действий.
- "Как загрузить файлы массово или интегрировать папки?" -> REST API `api/item/update`, утилиты, клиентская часть.
- "Как диагностировать сбой?" -> диагностика ошибок, журналы Elsa, аудит запросов, профильный раздел модуля.
- "Как работать с Revit?" -> плагин Revit, экспорт, публикация, внешние ссылки, редактирование файла.

## Термины, которые лучше сохранить в ответах

- СОД: система организации/документооборота Vitro-CAD.
- СХД: структура хранения данных.
- ТЭ: тип элемента.
- Lookup-атрибут: ссылка на элемент списка.
- `fieldValueMap`: карта значений атрибутов элемента в API.
- "Карточка проекта" / `project_scope`: ключевой объект для проектно-ролевых прав.
- "Реестр проектов": список или аналог, связывающий папку проекта и ролевых участников.
- Elsa: workflow-движок/менеджер процессов, где диагностируются Faulted-инстансы.

## Обновления

Официальный портал публикует материалы ветки Vitro-CAD 2026.1. Это не подтверждает, что корпоративная площадка уже обновлена до этой ветки. Для точных процедур установки, API и Revit всегда сверяй версию площадки и страницу соответствующего релиза.
