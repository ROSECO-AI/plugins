# Vitro-CAD — локальный MCP для вашего портала

Плагин подключает **ваш** портал Vitro-CAD MP к Codex Desktop, Claude Code или Qwen Code на Windows. Установщик запрашивает HTTPS-адрес портала, личный логин и пароль в отдельном окне. Права чтения, записи и удаления задаются учётной записью пользователя и правилами портала. Административный доступ для установки не нужен.

## Быстрый старт на Windows

1. Скачайте `VitroCAD-Local-MCP-Setup.exe` из [релиза этого плагина](https://github.com/ROSECO-AI/plugins/releases/tag/vitro-cad-local-mcp-v1.0.0). Если устанавливаете из исходников, скачайте ZIP репозитория и откройте `vitro-cad-local-mcp/start_install_windows.cmd`.
2. Запустите файл **обычным двойным щелчком**, не от имени администратора. Введите адрес портала вида `https://portal.example.org/`, свой логин и пароль. Отметьте агент, которым пользуетесь. Если знаете GUID списка реестра проектов вашего портала, введите его в необязательное поле; для входа он не нужен.
3. Дождитесь подтверждения входа. Полностью закройте и снова откройте выбранный агент; в новом чате напишите: «Проверь моё подключение к Vitro-CAD, назови портал и учётную запись. Ничего не изменяй». Проверка вызывает `vitro_whoami`, не создаёт тестовых элементов.

Файл `start_install_windows.cmd` использует встроенную среду Python, проверяемую по SHA-256, и не требует предварительной установки Python или 7-Zip. При повторной установке можно сменить портал и учётную запись; пароль для нового входа вводится в форме заново. Установщик намеренно не переносит сохранённые данные старого пакета `vitro-cad-team`.

### Что такое токен и где пароль

При входе портал выдаёт временный **токен** — подтверждение успешного входа для последующих запросов. Сервер получает и обновляет его сам; пользователю не нужно копировать токен. Адрес портала, логин и пароль хранятся для текущего пользователя Windows в файле `%APPDATA%\vitro-cad-local-mcp\credentials.dpapi`, зашифрованном системным механизмом DPAPI. Они не помещаются в настройки MCP и репозиторий. Не пишите пароль агенту в чат.

### Проекты и права

В Vitro-CAD нет подтверждённого для всех порталов общего GUID реестра проектов. Если он не указан, `vitro_list_projects` объяснит, какая настройка нужна; остальные инструменты могут работать с идентификаторами доступных пользователю элементов и списков. Можно переустановить пакет, указав GUID реестра, либо передать его в параметре инструмента. Наличие элемента в реестре само по себе не подтверждает права на его папку.

Доступны инструменты входа, чтения списков и элементов, скачивания, создания и изменения элемента, загрузки файла, перемещения в корзину и восстановления. Перед записью агент читает тип и текущий элемент; перед удалением сверяет идентификатор, имя и родителя. Повторное удаление того же элемента заблокировано локальным журналом, так как оно может привести к окончательному удалению. Сервер не повышает права пользователя. Обязательная двухфакторная авторизация в этой версии не поддерживается. Размер загружаемого файла до 100 МиБ.

### Другие агенты и повторная настройка

В окне установки можно выбрать одновременно Codex Desktop, Claude Code и Qwen Code. Claude Code и Qwen Code должны быть заранее установлены так, чтобы команды `claude` и `qwen` находились в системе; если их нет, установщик сообщит об этом. При использовании одного и того же Windows-пользователя они разделяют настроенный вход, а не создают копии пароля в каждой программе. Если в меню `/mcp` сервер не появился, перезапустите агент и откройте новую сессию. Для Codex Desktop завершите приложение также через значок у часов Windows, если он остался.

Для удаления сохранённого входа запустите установленный `%USERPROFILE%\.codex\plugins\vitro-cad-local-mcp\runtime\active\python.exe` с аргументами `%USERPROFILE%\.codex\plugins\vitro-cad-local-mcp\server\setup_windows.py --clear` под тем же пользователем Windows. Это не удаляет сам плагин и локальный журнал удалений.

## Для разработчиков и агентов

- [Подробная установка](INSTALL.md) и [готовое задание агенту](PROMPT_FOR_AGENT.md).
- `server/mcp_server.py` — stdio MCP; `server/vitro_api.py` — REST API; `server/credential_store.py` — DPAPI.
- `install_windows.ps1` и `bootstrap_windows.cmd` — установка; `mcp.json` и `plugin.json` — описание плагина; `skills/vitro-cad-local-mcp/SKILL.md` — инструкция агенту.
- `runtime/packages/` содержит официальные встраиваемые дистрибутивы Python для x64, ARM64 и x86; их SHA-256 проверяются при установке. `server/truststore/` используется для проверки HTTPS через доверенные сертификаты Windows; проверка сертификата не отключается.
- В этой версии поддержаны порталы с входом `POST /api/security/Login` и токеном в заголовке `Authorization` без `Bearer`. Другие схемы входа требуют адаптации; совместимость с каждой инсталляцией не гарантируется.

Справочные материалы `skills/vitro-cad-local-mcp/references/` — ограниченный снимок доступной официальной документации от 05.11.2026, не спецификация конкретного портала. Не включайте в GitHub реальные адреса внутренних порталов, идентификаторы списков, учётные данные и выгрузки. Лицензия нашего кода — MIT; отдельная лицензия `truststore` лежит в `third_party/`.
