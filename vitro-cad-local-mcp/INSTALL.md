# Установка Vitro-CAD MCP

## Пользователю Windows

1. Скачайте [VitroCAD-Local-MCP-Setup.exe](https://github.com/ROSECO-AI/plugins/releases/tag/vitro-cad-local-mcp-v1.0.0) и запустите обычным двойным щелчком. Не используйте «Запуск от имени администратора».
2. В окне укажите HTTPS-адрес своего портала (адрес страницы входа до пути, например `https://portal.example.org/`), личный логин и пароль. Отметьте ваш агент: Codex Desktop, Claude Code или Qwen Code. GUID реестра проектов — необязательное поле, если его знает администратор портала.
3. Нажмите «Подключить» и дождитесь окна с результатом. Перезапустите агент, откройте новый чат и попросите проверить `vitro_whoami`. При необходимости для списка проектов сообщите агенту GUID реестра; пароль ему сообщать не надо.

Если вместо EXE используется ZIP исходников, распакуйте архив и запустите `vitro-cad-local-mcp/start_install_windows.cmd`. Для установленных Claude Code и Qwen Code доступны их стандартные команды `claude` и `qwen`; установщик использует их, чтобы зарегистрировать MCP в личных настройках. Если они не найдены, установите нужный агент и повторите запуск. Он не удаляет другие MCP-серверы.

Для Codex Desktop, если установлен Codex CLI, установщик добавляет плагин в локальный каталог; иначе регистрирует MCP и навык непосредственно в настройках текущего пользователя. Не надо искать отдельную кнопку перезапуска MCP: полностью завершите приложение и запустите его снова. Для Claude Code и Qwen Code можно проверить подключение через `/mcp` в новой сессии.

Если вход требует 2FA, эта версия остановится с сообщением; логин и пароль сами по себе не позволяют обойти второй фактор. Если портал использует корпоративный сертификат, он должен быть доверенным на компьютере Windows. Не отключайте проверку HTTPS.

## Для агента, которому поручили установку

Прочитайте `PROMPT_FOR_AGENT.md`. Не принимайте пароль в чате и не записывайте его в команды, историю терминала, репозиторий или журналы. Проверьте, что пользователь запускает установщик под той же учётной записью Windows, в которой работает агент. Проверяйте только `vitro_whoami`, пока пользователь не поручит конкретную запись или удаление.
