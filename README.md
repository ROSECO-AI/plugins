# ROSECO AI Plugins

Репозиторий исходников плагинов. Плагин [Archviz Revit Render](./Archviz%20Revit%20Render/) содержит манифесты, навык, документацию и историю изменений. Текущая редакция: `2.1.1`.

Каталог `.agents/plugins/marketplace.json` делает плагин доступным для локальной установки в Codex из этого репозитория. Для работы нужен доступ к приватному репозиторию `ROSECO-AI/plugins`.
