# Текущее состояние

Версия: 1.0.0. Дата: 2026-11-27.

Источник публикации: `ROSECO-AI/plugins`, папка `bitrix24-local-mcp`.
Реализация основана на ранее использовавшемся локальном Python-коннекторе.
Публичный пакет не включает реальные настройки, вебхуки или корпоративные данные.

## Реализовано

- Python 3.10+, stdio MCP, стандартная библиотека.
- Семь инструментов, универсальные чтение/запись, сохранение полной REST-оболочки.
- Установщик для регистрации реального интерпретатора; отдельная конфигурация каждого портала.
- Безопасная настройка через скрытый локальный ввод; запись выключена при первичной настройке.
- Плагин каталога ROSECO AI с кодом, установщиком, инструкциями и промптом.

## Проверка

- macOS: 34 теста прошли, включая реальный запуск stdio-процесса и MCP handshake.
- Codex CLI 0.169.0: установка плагина в изолированном профиле подтверждена как installed/enabled; регистрация MCP и повторная установка прошли.
- Реальный портал: профиль, текущий пользователь и список задач успешно прочитаны новой реализацией; next и total сохранены. Содержимое ответов и секреты не включены в публикацию.
- Запись проверена с синтетическим транспортом; реальных изменений в портале не выполнялось.
- [GitHub Actions](https://github.com/ROSECO-AI/plugins/actions/runs/46012964996): все шесть комбинаций Windows/macOS/Linux × Python 3.10/3.13 успешны. В каждой выполнены 34 теста, установка/повторная регистрация MCP и установка плагина через Codex CLI.
- На Windows проверены ACL файла настройки, UTF-8 MCP и установка в путь с кириллицей и пробелами. Это проверка на CI-хостах; отдельный пользовательский Windows-компьютер автоматически не перенастраивался.
- Проверенный код: коммит `45d37ccdfe69db923c9515b4a87ef7afe897e355`. Последующее уточнение документации не меняет исполняемые файлы.

## Практические ограничения

- Фактические возможности зависят от REST, подписки, scope вебхука и прав сотрудника.
- batch, REST3, OAuth-приложения и входящие события не реализованы.
- Подтверждение конкретной записи обеспечивает клиент; локальный флаг включает возможность.
- Плагин устанавливает навык и исходники; MCP регистрируется установщиком отдельно.
- Полный парный прогон против официального hosted MCP не выполнен. Его ограничения нельзя выводить из одного скриншота.
